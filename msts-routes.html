How to Install MSTS Routes

Quick 4-step guide to get any route running inside Microsoft Train Simulator or Open Rails.

1

Download & Extract

Download the zip/rar archive and extract using WinRAR or 7-Zip.

2

Copy to Routes Folder

Move the route folder inside .../Train Simulator/ROUTES/.

3

Run Installme.bat

Double-click installme.bat inside the route folder to copy required default assets.

4

Launch & Enjoy

Open MSTS or Open Rails, select the newly added route, and start your session!
